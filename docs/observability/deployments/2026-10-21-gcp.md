# GCP logging deployment — 2026-10-21

The collector is running in project `glid-app` on VM `argos-host`, zone
`us-central1-a`. Its authenticated HTTPS endpoint is
`https://argos.34.135.204.210.sslip.io/observability`.

## Installed services

`terra-observability.service` runs as a dedicated unprivileged user and listens
on `127.0.0.1:7450`. Caddy exposes only the `/observability/*` route. Existing
dashboard routes and the Zenoh TLS listener on port 7448 were preserved. The
router process remained running throughout installation; Caddy was reloaded.

The collector has a 768 MiB memory soft limit and 1 GiB hard limit on this
2 GiB VM. Storage budgets are 4 GiB events, 3 GiB attachments and 1 GiB exports,
with 30-day retention. Data is under `/var/lib/terra-observability`.
The pinned replay environment under `/opt/terra-observability` uses Python 3.12
and Rerun SDK 0.39.0.

Hash-only credentials are installed at
`/etc/terra-observability/credentials.json`. Raw client tokens are kept outside
version control. Original proxy configuration is backed up at
`/var/backups/terra-observability/20261021/Caddyfile.before`; the installer also
saved `/etc/terra-observability/proxy-backup.NEUJDn`.
