# Simulator image

The Docker image and dev container that ran the Bevy world moved with the simulator to [Zorvane](https://github.com/Super-Yojan/Zorvane). Run that world with `cargo run -p zorvane` from a Zorvane checkout. The Zenoh prefix is still `terra/rover`, and the `TERRA_*` variables still apply.

This repository's container is the Raspberry Pi rover image. See [compiled Pi executable and installation](hardware/INSTALL.md) and `packaging/rover/Dockerfile`.
